# ♻️ E-Waste Pickup and Recycling Portal

A web-based platform designed to make electronic waste collection and recycling easier, organized, and accessible.

## 📌 About the Project

The E-Waste Pickup and Recycling Portal connects customers with e-waste collectors through a simple online platform. Customers can submit pickup requests, track their request status, and contribute towards responsible electronic waste disposal.

## ✨ Features

### Customer
- User Registration and Login
- Submit E-Waste Pickup Requests
- Select E-Waste Categories
- Track Pickup Request Status
- View Previous Requests

### Admin
- Admin Dashboard
- View and Manage Pickup Requests
- Approve or Reject Requests
- Create Collector Accounts
- Assign Collectors
- Update Collection and Recycling Status

### Collector
- Separate Collector Login
- View Assigned Pickup Requests
- Access Customer and Pickup Details
- Update Collection Status

## 🛠️ Technologies Used

- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Development Tools: Visual Studio Code, XAMPP, MySQL Workbench

## ⚙️ Installation and Setup

1. Install XAMPP and start Apache and MySQL.
2. Clone or download this repository.
3. Copy the project folder into the XAMPP `htdocs` directory.
4. Open phpMyAdmin or MySQL Workbench.
5. Create a database named `ewaste_portal`.
6. Import `database/ewaste_portal.sql`.
7. Copy `db.example.php` and rename the copy to `db.php`.
8. Open `db.php` and enter your MySQL username and password.
9. Open your browser and visit:

   `http://localhost/ewaste_portal/`

## 🗄️ Database

The project database export is available in:
